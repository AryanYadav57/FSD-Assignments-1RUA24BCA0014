# TechConf 2026 Registration Form

A clean, modern React Native for Web application built for registering attendees to TechConf 2026. 

## Features
- Client-side validation
- Modern UI (Glassmorphism inspired, minimalistic)
- Responsive design
- Integrated Toast Notification feedback

## Setup Instructions

1. Install dependencies
```bash
npm install
```

2. Start the web app
```bash
npm run web
```
