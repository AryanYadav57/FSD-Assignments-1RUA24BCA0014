# Department of Computer Applications

Static replica of the RV University Department of Computer Applications page.

## Run locally

From this folder, start a static server:

```powershell
python -m http.server 4173
```

Then open http://localhost:4173.

The page uses Bootstrap, Swiper, Font Awesome, AOS, and Poppins from their public CDNs. Images available from the reference site are included under `assets/`.
